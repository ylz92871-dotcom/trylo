## 3. 包内工作与验收

### WP26.1 后台任务与长进程

接通根 CLI 与真实消费者：daemon start/stop/status，后台任务 ps/logs/attach/kill，本地 worker 领取既有队列任务。证明前台退出后继续、日志有界且游标不重放、终态可查询、取消回收后代、重启恢复与 PID 复用/陈旧记录处理。独立 worker 不重复 Session/Permission owner。

### WP26.2 定时执行与条件监控

创建/列出/删除到真实执行与结果落盘全部接通；sleep 可取消，条件变化可触发、去重与停止订阅。保留已修 DST 红例和时钟注入；明确删除对未领取/已入队/运行中任务的语义。双进程争抢、崩溃窗口、重启与未知副作用按既有耐久合同验证，不自动重做 unknown。

### WP26.3 持久后台委派与已有远控

先追现有入口/认证/审批/取消/重连消费者，再补新版薄接线。真实工单应包含预期内容、执行前后磁盘差异和终态；提交后退出客户端，再重连查询真实进展。已有 stub、模型自述和 completed 不能替代产物证明。权限只收窄，审批/拒绝/取消在执行 owner 生效。
