## 3. 包内接线任务与验收

### WP01.1 继承 W1 耐久接点

施工：读取 W1 冻结与独立复核证据；确认 issued→执行→result durable→settled 生产链仍在，保留已经通过的回归。

验收：杀进程发生在提交前、执行后和结果落盘前时，恢复的因果事实与磁盘一致；不重做已有持久机械层。

### WP01.2 未闭合流与恢复投影

施工：增量 delta 的保留、截断、部分工具参数及重复序号先定合同，再接唯一 writer。

验收：截断尾行、重复事件、部分流、存储失败均有显式结果；不把未完成工具参数当可执行动作。

### WP01.3 unknown 人工核对

施工：给 reconcileRequired 一个真实 CLI 消费入口，核对实际动作并追加事实，禁止猜成功和自动重放。

验收：核对成功、仍未知、取消和再次崩溃均能恢复；无证据时保持未知，不重复写文件/执行命令。
