## 3. 包内接线任务与验收

### WP09.1 预算与裁切

施工：复用 Codex token/compact 和旧压缩外围，模型能力输入经现 provider 合同注入。

验收：token/上下文超限、工具超长结果和保留策略可复现；不裁掉动作与结果的配对事实。

### WP09.2 多次压缩与约束保留

施工：冻结摘要/原消息关系、压缩提交点和失败恢复，保留用户最新 steer、审批与任务目标。

验收：连续两次压缩后真实任务仍遵循原约束和最新输入；失败不覆盖原会话。

### WP09.3 预算中断后续跑

施工：把上下文/预算终止原因和 resume 路径接实际 CLI，不从缺失流推断任务完成。

验收：中断→resume→磁盘正确结果→项目验收成立；仅 same session resumed 不算任务恢复。
