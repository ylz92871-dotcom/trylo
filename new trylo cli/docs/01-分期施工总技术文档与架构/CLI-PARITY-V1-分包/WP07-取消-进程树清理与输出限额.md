## 3. 包内接线任务与验收

### WP07.1 取消链贯通

施工：从 CLI/协议 interrupt 到 loop/provider/tool/helper 共用取消语义，区分观察超时与任务终态。

验收：取消在排队、启动、运行和结束竞态均有唯一终态；UI 停止不等于工具停止。

### WP07.2 进程树与句柄回收

施工：直接复用进程组/JobObject 清理；明确 graceful→force 与实际退出事实。

验收：Windows 子孙进程、管道/PTY 句柄实际消失；重复取消幂等；清理失败可见而非吞错。

### WP07.3 输出上限与大输出

施工：复制成熟限额与裁切机械层，保留 stderr、退出码、截断 metadata 和可取回结果定位。

验收：多字节字符、无换行大输出、超限和后续轮询有界；截断不被当命令成功证据。
