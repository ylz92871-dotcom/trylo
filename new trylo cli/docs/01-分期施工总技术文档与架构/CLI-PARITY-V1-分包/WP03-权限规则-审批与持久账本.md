## 3. 包内接线任务与验收

### WP03.1 冻结权限 scope 与 lifetime

施工：区分持久 tooling 单次 file ledger、临时 session grant、规则配置和撤销；先冻结指纹/寿命/消费语义。

验收：F02 不把两个缓存互当授权；grant 精确匹配动作及参数，过期、重启、撤销与重复消费可判定。

### WP03.2 规则与审批接线

施工：取旧规则读写与 Codex policy 机械层，接唯一 PermissionService；审批详情显示真实目标。

验收：批准、拒绝、取消、EOF 和动作参数变化各有回归；问答答案不能成为权限票据。

### WP03.3 账本实际消费

施工：普通工具、委托、Hooks 与调度调用同一入口记录 issued/committed/unknown。

验收：从实际命令拒权到持久核对形成闭环；没有“构造账本即接通”的假完成；崩溃不扩权。
