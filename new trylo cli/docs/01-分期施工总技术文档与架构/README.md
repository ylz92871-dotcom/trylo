# 分期施工总技术文档与架构

每一期开始生产编码前，必须在本目录有一份状态为 `已批准` 的总技术规格。规格至少包含：目标/非目标、领域边界、数据与状态所有者、公共合同、状态机、依赖、任务包、测试矩阵、退出标准、迁移/回滚和风险。

本目录包含现行规格和已改名的历史规格。所有新规格必须先服从 `../00-总领/TRYLO-LEARNING-AGENT-顶层架构与目标.md`；旧阶段顺序不得把学习降格为传统 CLI 完成后的外挂。
