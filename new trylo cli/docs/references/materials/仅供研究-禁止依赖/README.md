# 仅供研究，禁止依赖

> 分类导航，不是设计权威。原始来源卡保存在[历史来源归档](../../../../../_workspace/archive/tracked/new-cli-reference-materials/仅供研究-禁止依赖/)。新资料进入 `_workspace/research/<主题>/`。

本目录中的材料当前不得进入 package manifest、lockfile、源码、测试 fixture、构建输入、发行包或运行时下载路径。允许的产出只有独立撰写的架构比较、接口需求和测试思想。

Apache-2.0 不再天然属于本目录。若一个 Apache-2.0 组件能放入 B/C/D 级，应在 `../Apache-2.0-可隔离评估/` 建来源卡；若整套 runtime 因核心渗透仍被放在这里，来源卡必须明确真正阻断的是架构、维护或其他许可风险。
