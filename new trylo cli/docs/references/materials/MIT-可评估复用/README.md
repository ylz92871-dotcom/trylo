# MIT 级候选暂存规则

> 分类导航，不是设计权威。原始来源卡保存在[历史来源归档](../../../../../_workspace/archive/tracked/new-cli-reference-materials/MIT-可评估复用/)。新资料进入 `_workspace/research/<主题>/`。

放入本目录不等于获准依赖。每个候选必须先完成来源卡、固定版本、文件级许可证和完整传递依赖闭包审计，随后由当前期 ADR 决定 `直接采用` 或 `隔离采用`。

本目录保留 MIT/ISC/BSD 候选。跨许可证的 provider 对比卡可能同时列出 Apache-2.0 候选；实际 Apache 来源卡和 NOTICE/架构等级证据应放在 `../Apache-2.0-可隔离评估/`。
