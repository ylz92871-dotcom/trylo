## 1. 层：顶上控制板只点名、只给额度

顶上那块学习控制板不与某个子系统的内部循环纠缠。它只做三件事：

- 判断采集开不开、总学习预算还剩多少；
- 发一张工单：本轮叫「方法子系统」，还是「技能子系统」，还是 idle；
- 给一截额度（这轮方法子系统可以花的 token / 调用），然后不看了。

它**不**替子系统挑卡、不数张数、不写 prompt、不每回合跑一次 LLM 去「检索该带哪张」。上一版把「延迟、留不留、带几张、怎么捞」全塞进顶板，那不是分层，是把整个 Agent 学习挤进一个进程角色，做成保姆。顶上调度器越宽，系统越不优雅；下面各子系统自己运转，顶上只分配额度与点名。

Agent 学习的模块按总领的 what 各自成子系统：方法、技能、工作流、工具、检查、路由。本文件只写**方法**这一个子系统，其余不进本轮。

## 2. 机会 ≠ 课题

传感器（工具失败、同指纹连撞……）只做一件事：给这一拍**放权**——方法子系统被允许带着学习意图干活。

学什么由执行里的 LLM 自己定，不由失败码指定章节。把失败码映射成固定课题（例如「路径逃逸 → 只许用工作区路径」）学到的只是传感器那一层；真实任务的失败根因常更复杂，这种卡的长期价值很低。传感器以后会不够，那是传感器自己的事，不是把课题写死。

## 3. 共枪：学习意图进执行枪，输出走附加通道

不为学习另开一轮。执行环本来就要打模型；放权的那一拍，在模型「还在想、还没往工具上走」的那段提示里加一个**学习意图**。工具该怎么 call 还怎么 call。

贵的是多出来的那截输出（经验卡），不是整轮复读。所以输出走**附加通道**：卡和钩子走一个固定形状的附加输出，不与 tool_call 抢格式。单独 worker 那一轮可以丢掉。

**末拍共存。** 「枪打完马上结束」是少见情况，不把整条机理改成末拍专用。常见走下一拍执行枪；若这一拍就是收工，就从这一枪的附加通道收卡，不另起学习枪。特殊情况特殊处理。

## 4. 留卡：过门即入变体档案，下一拍是记账不是删档开关

- 过代码门的卡**立刻**进 shadow 档案，当**变体**，不当真理。不要等「有用」才落盘——那是拿一次偶然当终身判决。
- 下一拍工具结果给这张变体**记账**：同类失败没再出现 → 记一次支持；还是同一脚 → 记一次反例（dormant / counterexample），先不当死。
- 同一 niche（同一适用条件）里可以**并存几张变体**；上场时 keep-best，不是并排塞十张同一句话。
- 档案内的指针挪到「这 niche 当前最好的」，旧版本仍在档案里**能回滚**。

这才叫留。`if useful: save` 不是留。

落盘跟 `tryloHome` 走，和 session 同一套家。本步仍然只标 **shadow**，不要 active。

## 5. 标签：受控子集，可追加，不自由派

- 系统里有一份**标签子集**（词表），不是无限词表。
- 每次把学习意图打给模型时，提示里**写明当前有哪些标签**。
- 出卡优先用现有标签。觉得不够，允许**申请追加**（有数量帽，一拍最多 1～2 个，且要带一句极短释义），进词表。禁止把标签写成自由句子。
- 词表膨胀、合并同义、谁有权删：标**待优化**，留给反思或以后再谈。初版只保证「能用、能加、不自由派」。

课题仍由模型定。门只卡形状与禁区（权限、跳过沙箱），不卡「必须学路径」。

## 6. 钩子：限定格式，不是自由文本

上一拍模型留下一个**钩子**：不是光一个标签，而是「这个标签里下次还需要什么」——带若干标签加一句限定，有长度帽。

- 空钩子 = 本拍交白卷，或按当前执行状态做极轻检索。**空钩子不是「全库上场」**。
- 钩子有格式，就是不许写成「我需要关于一切的经验」。

## 7. 取卡与上场：编译 + 预算，不是检索

- **取卡不跑 LLM。** 标签加钩子做本地检索，像人被场景勾起经验，不是每回合请顾问翻书。
- 适用范围（适用条件）在**抽卡那一枪就写进卡里**，上场时**免费求值**，不再打一枪去「搜索」。卡带适用范围是卡的一部分。
- 上场接近**编译**，不接近 grep：看当前执行状态（工具目录、本 session 最近失败、压缩后上下文还剩多少）→ 求值各变体的适用条件 → 在**方法经验的 token 预算**里按分数装包，装满为止 → 编成**一条**短 system（或固定槽位），不是 N 张卡 N 条 system 往上叠。
- **预算是硬顶，张数是结果。** 有时 1 张，有时 3 张短的，有时 0 张。**0 是正常，不是失败。**
- 「防爆」用**上场预算**管，不是用「只准一张」管。K=1 死板，是把防爆做成了禁止组合。
- 每回合再打 LLM 做检索，是把学习预算浪费在找卡上。不行。

## 8. 超注入上限怎么排序（**已拍：B 双槽**）

A（先匹配后次数）、B（双槽）、C（次数带衰减）三案中，所有者拍 **B**：

> 帽不是「前 K 张同一种办法」，而是两类各有名额。例如总共 3：
> - **至多 1 张**「钩子最贴的」（这一拍场景）；
> - 剩下给「**词表命中且用得多的**」（稳态经验）。
>
> 新卡就算次数是 0，只要这一拍钩子点得很死，仍能占那 1 个贴合槽。这样既不会全是老卡，也不会全是上一拍随口要的。

附带的三条口径（同轮讨论有效）：

- **第一键不能是生次数**（注入过 ≠ 用过），匹配优先，次数只做同分打破。
- 「使用次数」的定义待优化；初版若太难计，可以「上场一次记一次」，但排序不得退回到「生次数第一」。
- 不做抽签。

## 9. 改卡：只在命中集上改

- 先检索，**只许改命中集里**的卡。不让 LLM 扫全库。
- 一拍最多改命中集里的，且**改完体积不能涨过帽**，防止「更新」变成把全书抄进一张卡。
- 回滚可以很弱（反思才收拾），但禁止一次更新把检索面搞爆。

## 10. 反思：用户主动点，禁止自动

全库扫描、去重、合并标签、优化卡：这是**反思**，交给用户主动点，因为贵。禁止自动跑，也禁止深夜空转——那会把调度器又做成保姆。

## 11. 换代关系：第一步哪两句被改

第一步仍然有效的部分：延迟、一枪、代码门、本 turn 可再注入一张新卡、默认关学习。

改掉的是第一步里太糙的两句：

| 第一步 | 本机理 |
| --- | --- |
| 「有用才进档案」 | 先归档（过门即变体），再记账（支持 / 反例） |
| 「跨 turn 零张 / 最多一张」 | 跨 turn 由板编译一包，受 token 预算约束；张数是结果 |

## 12. 明确不做

## 15. 模型这一段输出是两样：卡 + 总结

- **卡**：机器读的。过门后进影子档案当变体，用户默认不被打扰。
- **总结**：人读的。就是给用户看的那一句——「这轮我注意到了什么、记下了什么」。
- 两样走同一条附加通道，但**受众不同，不许混成一样东西**：卡不是给人看的（紧凑、字段化），总结不是给机器用的（一句话、看得懂）。
- 总结初版**一句话、不展开**；想看起因去查卡。
- 两样的形状、以及「有卡无总结 / 有总结无卡」怎么处置，属**待优化**；初版只保证两样能分开出来。

## 16. 可见性与审核：分三层，不是「全审」也不是「全不可见」

所有者否掉了「每张卡都给用户审」——那样用户会烦，学习省下的返工会被审核时间吃掉，**学习反而没有价值**。

判据：

> **价值 = 省下的返工 − 用户的审核时间**

所以设计目标是**把审核次数压到接近 0**，不是「审得准」。

可见性分三层：

| 层 | 内容 | 打扰 |
| --- | --- | --- |
| **拉取层** | 全部卡、谁在起作用、谁被反例按下、谁被撤 | 零打扰，用户主动看 |
| **轻提示层** | 每轮学到的 + 那条总结（一句话） | 不打断，有日/周顶 |
| **推送层** | 装工具 / 对外贡献 / 改权限；以及**跨任务转正** | 要点头，且**攒一批一起问** |

**审核点挂在「生效」，不挂在「生成」。** 一张卡生成时不打扰（它还没影响任何东西）；它要**跨任务常驻**时才需要人工闸。日常靠「影子 + 试用 + 可撤销」三道兜，不靠用户的眼。

**人工审核仍然保留**，但定位是**特殊问题特殊分析**，极低频（可能一周都不响一次）。理由：总领定了「沉默 ≠ 同意」——完全没人点头就能常驻，等于让 Agent 给自己发永久通行证，这条不松。

锚点（总领已定的，不是新发明）：§5.3「永远人审」只有三样（装工具 / 对外 / 改权限）；§3.10 打扰要算长期认知价值、有日/周顶、连续无视降权；§3.8 Commitment 六态 + Receipt 可见可撤销。

## 17. 存储分层：控制板管「谁的账」和「什么时候能花」，子系统管「这笔账怎么记」

- 控制板保有 `Proposal / EvidenceBundle / Activation` 与 `Clock`，并**提供账本端口**。
- 各子系统自己那一族的**变体并存、keep-best、shadow 指针、回滚，在子系统内部完成**，只经控制板的账本端口存取。
- 子系统**不得自建第二本变体账**（`AGENTS.md`：一个概念只有一个写入入口）。
- 这条与总领 §5.4 原文（把 `Variant Archive` 与 keep-best 写在控制板名下）冲突；**总领 §5.4 已按本条修正**。

## 18. 上限数字（已拍）

- **张数上限 8，只当兜底**；总字符 **1200**；单卡 **900**。
- 主顶是**预算**，不是张数。早先写成「张数 ≤ 3」是把主从做反了，现修正——对上 §7「预算是硬顶，张数是结果」。
- 槽预算的单位是**字符**，不是 token：算 token 的估算器在 loop 侧，学习层不许 import 它。改 token 口径需 loop 侧配合，标**待优化**。
- **0 张仍是正常。**
