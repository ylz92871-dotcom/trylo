# 中央冷启动与反馈决策：本轮采用的模型

本记录只说明进入实现的模型与推导；工程接线及证据见[P05交付记录](../../02-分期工程产出/P05-Experience-Learning-V0.3/2026-11-04-实现与接线-中央冷启动及反馈决策.md)。原条件响应高斯/Beta、时机证书和有限资源Bellman均复用，不采用开发草案中的调用方完整世界DTO、额外精度校准目标或任意variance bonus。

## 1. 无成熟经济历史时，目标仍须明确

完全没有收益/观察模型时，两种与当前事实相同的世界可以使不同机会最优，数据本身不能选出“真正净收益最高”的首投。工程不能因此永久不学，也不能捏造经济增量；本轮使用原PA已聚焦的真实有限阶段目标，按同一事前交付/检查/采用标准记0/1。不同标准不混加。

对Bernoulli(p)，score为`y/p-(1-y)/(1-p)`，Fisher information为`1/[p(1-p)]`。Jeffreys规则归一化后为`Beta(1/2,1/2)`；观察s/f后为`Beta(s+1/2,f+1/2)`。这是一项proper参考模型选择，不是观察到50%成功，也不保证对所有选择过程“无信息”。

原始[Jeffreys 1946出版页](https://royalsocietypublishing.org/doi/10.1098/rspa.1946.0056)本轮访问403，只用原档案核出版信息，未声称读到正文。可读作者出版稿[Ly等，2017，A Tutorial on Fisher Information](https://pure.uva.nl/ws/files/21885430/A_tutorial_on_Fisher_information.pdf)式8/16/18支持相应规则；上述Bernoulli推导独立给出。

同族须由来源声明语义、抽样/停止、条件与资源协议兼容；revealed-label点预测依赖稳定/可交换及ignorable揭示的工作假设。pending保留总体与补全范围，不当失败、置信区间或额外独立试验。

## 2. 真正的信息价值在观察后的可执行选择

[Hay等，Selecting Computations，UAI 2012](https://arxiv.org/pdf/1408.2048)的metalevel停止问题，以及[Frazier、Powell、Dayanik，2009](https://optimallearning.princeton.edu/Papers/Frazier%20Powell%20Dayanik%20CorrelatedKnowledgeGradientJOC.pdf)的观察后选择顺序，支持先对未来可见观察积分、再按后验选择动作。它们没有提供Trylo的先验或领域收益，也不直接覆盖真实域内互补/收费协议。

本轮从primitive Beta后验、真实阶段、硬reserve和明示utility fee编译原有限可观察图；终点只记unique完成次数。例：真实A1/A2同族、B异族，三个都cold参考、预算两项。先A1：成功后A2预测3/4，失败后B仍1/2。根值`1/2+(1/2)(3/4)+(1/2)(1/2)=9/8`，而固定两项值1。9/8由原Bellman回溯产生，不能手填进terminal。

若没有真实A2，就不能复制A1造信息价值。同一objective一经尝试，其替代depth在当前图中全部退出，防失败后又当新独立trial。原模型之外的future calendar、未确认退款或新的域内资产选择不被补造。

## 3. 资源档位不必二选一：全隔离或强行共享

来源先声明同语义协议，真实policy/reserve/prompt定义treatment。两个proper有限结构假说为shared p与各treatment独立p；各p均Beta(1/2,1/2)，结构先验对称1/2，仅表示这两个参考假说对称。原ordered Bernoulli evidence和log-weight核更新权重，假想分支继续更新两者；既不假定tokens越多越好，也不宣布caps无影响。

独立手算：A成功/B失败时，shared evidence=1/8、independent=1/4，posterior shared mass=1/3；A下一均值2/3、B为1/3、未见C为1/2。实际planner合同还检查观察分支后不同treatment的概率与首选变化，而非只检查fit返回值。

## 4. 有真实whole-window bounds时的工作经济模型

原source声明支持[L,U]，R=U-L。uniform参考的均值`(L+U)/2`、方差`R²/12`；有界变量由`E[(X-L)(U-X)]>=0`得`Var(X)<=(U-E X)(E X-L)<=R²/4`。本轮取后者为固定工作likelihood variance代理，不称实测Gaussian噪声。完整事实进入原高斯核一次；由其推得prior等价precision=3，不是手调pseudo-count。

同一fixed-R单截距类有`Σ(Yi-theta)²=Σ(Yi-Ybar)²+n(Ybar-theta)²`，所以用Ybar、噪声R/n给同一proper先验得到完全相同参数后验。源历史可以积累，原dense核仍只收1行；完整unit/source refs保留。这不保持完整数据marginal evidence，不能拿聚合密度选择不同R或结构假说。本实现仅单fixed component消费mean/cov。

没有合法bounds的v1不借v2范围。原first2 Gaussian有效则保留；无噪声识别而有完整事实时仅给经验均值和null方差，并披露稳定运输/揭示假设。零方差样本不是现实确定性；真正来源声明的点支持则是另一回事。

## 5. 代价和未决数据决定停止语义

只有非负完成次数与硬资源帽时，proper Beta有限失败后仍p>0，通常不会凭失败次数经济止损。要低p主动不投，需要真实同单位费用、用途截止或其他明确目标；不偷偷加入阈值或token价格。

经济负值约束仅为当前模型期望，携带其假设；pending有范围时比较所有合法处理方案的净值上界，不能只比较gross与0。未知反馈不阻断无关候选。真实call/step/token占用与资金释放继续由原账本决定，预测均值没有退款权或权限权。

真实source结果支持是独立于工作prior的逻辑信息。若该实际支持的最大gross（deadline保守包含0）扣除每个合法处理的明示费用仍严格小于0，即使没有完整样本也能给负净值上界；输出必须标明是source支持的ceiling，不能说成观察到的均值。只有工作prior均值为负而实际支持仍可正时，不采用这项约束。

详细独立小反例、原红和本轮必要检查放仓库根`work/central-decision-continuation-20261104/`；本记录不把未运行合同、正常交付回执或来源快照当学习净收益已验证。

## 6. 部署条件收益不是整次学习收益

原预测研究已区分learning-plan、continuation和deployment response。100次assignment仅10个合格产物、且这10个全采用时，采用条件收益不能当100次assignment的收益。令D为与同一目标定义匹配的部署事件，完整分解为`E G = P(D) E[G|D] + P(not D) E[G|not D]`；非部署影响未必为0，proposal完成不等于D。若参数相关，还需对同一joint posterior积分，不能直接乘两个边际后验均值。

本轮不发明这些缺失的gate/通道。旧deployed历史仅保条件诊断，哪怕正负均值或支持很强也不越级用于whole investment。新v3直接注册完整learning policy固定assignment人口，结果含失败/未采用的真实影响或unknown，而不是只筛成功部署者；这种直接whole-policy响应才消费原经济决策核。登记须早于原始pending assignment、measurement出生，不能在看到学习产物后再选成功人口。正常没有这类真实协议时，由独立明确的阶段目标先投并学习，不称业务净收益已识别。
