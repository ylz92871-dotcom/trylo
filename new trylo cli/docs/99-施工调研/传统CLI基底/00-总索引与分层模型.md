## 分层模型（六篇共同支撑的一句话）

```
┌ cli-host（命令面/TUI/非交互/stdin/退出码）      ← D6：只做输入投影与渲染，不写第二份循环
├ protocol（Envelope + journal 投影出口）          ← D5：ACP/ag-ui/a2a 均是可选投影，不是内核
├ loop（runTurn 解释器 + attempt/取消/重试）       ← D1：七家 while 循环的等价物，迭代钩子需补
│   └ 迭代间隙三钩子：预算检查 / steer 排空 / compaction 判定（D1 §8）
├ domain（reduce 纯函数状态机 + EffectCommand）    ← D3：终态集与审批四态已领先，缺 args 维度
├ ports（provider/tools/permission 自有词汇）      ← D2：翻译层每协议一纯函数；SDK 类型止于适配
└ adapters（真实 provider / MCP / session-store / checkpoint） ← D2/D3/D4：目录注入，不进 loop
```

## 明确不是结论的东西（防串台）

- 协议（ACP/ag-ui/MCP/a2a）都不是 Loop；四个都只是内核事实的单向投影（D5）。
- LangGraph 类图引擎不是 CLI 内核（D1 §1 证据：七家无一使用）。
- goose 状态机双轨灰度、aider litellm 直通、各家特有花活（recipe/scheduler/kanban/doom-loop 当验证用）见 D6 §9 与表 C 纪律，不进 P0。
- mini-swe-agent 只是最小纵切参照物，不是功能清单。
