## 行为与边界

1. 构建目录继承的 Low 标签会降低暂存 Node 的实际进程令牌，导致普通目录写入 EPERM。只给构建副本设显式 Medium 标签，不改变 DACL、不请求管理员权限、不修改用户安装的解释器。便携启动脚本检查固定的随包路径；开发和发布暂存共用同一修复规则。
2. Windows 输入健康探针同时读取 Python 令牌、实际启动器文件标签及基础解释器标签。High Python 不能掩盖 Low 启动器；输入权限状态不再被版本缓存冻结。
3. 工作区内绝对文件路径是相对路径的兼容别名，仍经过词法边界、真实路径与链接检查。工作区外、设备路径、驱动器相对路径保持拒绝。shell cwd 保持原合同，只接受相对目录及字面工作区根目录别名。
4. v1→legacy→v1 切换创建新 v1 会话，由可见聊天历史重新建立上下文，避免恢复遗漏中间 legacy 轮次的旧 journal。替换进程使用被替换协议的取消通道；连续 v1 轮次仍续接原会话。
5. MCP 图像物化使用 MCP 适配器自己的结果类型，不再同时依赖通用 ToolPort 合同；未放宽架构扫描。
