## 需求与验收边界

按用户授权，用临时火山凭据测试当前 subagent，保留失败后修复可复现缺陷。覆盖真实子任务读文件、并行隔离、同一实例追问、队列替换、fork、恢复、取消、父任务关闭及 provider 失败。凭据仅通过测试进程环境传入，未写入源码、配置或本报告，未切换全局 provider。

真实入口为当前 CLI 编译产物和相同生产运行时。Desktop 验证为 React/宿主适配器到真实 CLI 进程、合成本地 endpoint 的集成测试；不代表原生 WebView2、安装包或长期稳定性验收。

## 已复现的四处问题

| 问题 | 修复前证据 | 修复与预期行为 |
| --- | --- | --- |
| 追问等待期间泄漏上一轮答案 | 真实火山子任务第二轮处于 working 时，output 仍是第一轮读文件结果；回归断言得到 answer-1 而非空串 | 只有满足最新已接受轮次的报告才能作为当前 output；待完成期间返回空串 |
| 连续输入后替换队列会提前满足等待 | 同一微任务间隙先给等待中的 worker 投递，再 interrupt 替换尚未消费的队列；旧实现依赖尚未更新的 activeRound，误报 timed_out=false | 信箱在交付和取出输入时计算已接受的最终轮次；观察者使用该事实，不再根据滞后的 worker 回调猜测 |
| fork 遗漏父任务当前消息 | 未修复的真实 CLI 连续两次 fork 都无法返回父消息中的 FORK_LANTERN_6721；原接线只传初始化系统/项目说明 | 在父 provider 的请求边界保存最新消息快照，子 provider 不写入该快照；覆盖最新父消息与兄弟隔离 |
| fork 混入父工具清单与任务身份 | 中间候选已能看到测试词，但子任务尝试执行父任务的 spawn_agent，碰到未挂载工具并耗尽 token 预算；该轮明确判失败 | 复用循环的 toolListMessage 精确识别并排除父任务生成的工具清单；子循环继续生成自身清单；追加委派身份说明，区分父历史和当前子任务 |

修复保留 SubagentRuntime 的生命周期与权限所有权，不增加工具权限，不改变默认并发、token 或超时上限。fork 快照仍通过现有文本 transcript 转换机制进入同一执行循环，没有另建执行引擎。

## 真实调用结果

- 预检：火山 Coding endpoint 返回 HTTP 200；请求别名 ark-code-latest，预检响应的实际模型为 deepseek-v4-1-flash。此处不将别名视为恒定模型版本。
- 两个真实子任务分别通过 read_file 读取合成的 alpha.json 和 beta.json，返回 ALPHA_7129/37 与 BETA_8241/58。
- 仅给 alpha 追问后返回 ALPHA_NEXT=42；beta 保持自己的第一轮结果。pending 快照的 output 为空。
- close/resume 后仍能返回 alpha 的原始 code 与 amount。
- 不存在的子模型得到 HTTP 404，并以 failed 结束；未把 provider 失败伪报完成。
- 请求已开始后的 force close、父任务关闭均返回 cancelled；清理后 active 实例列表为空。
- 最终真实 CLI fork：子提示未包含测试词，子任务第一轮准确返回 FORK_LANTERN_6721，随后正常关闭；没有再次尝试嵌套派发。
- 真实 CLI 并行编排完成两次派发、两份结果收集、仅 alpha 的追问与双方关闭。

## 可读性、架构、兼容与供应链自审

- 可读性/可维护性：信箱拥有输入消费事实，观察者拥有轮次结果，runtime 继续拥有终态和资源槽。fork 快照只在父请求边界刷新；父子 provider 不混用脚本或 continuation 端口。
- 架构：变更限于 subagent 与 CLI 组装层，未向执行核心引入 Desktop/UI 类型；复用当前 runTurn、ToolPort、toolListMessage 和 transcript。
- 兼容：工具参数与协议字段不变；working 阶段 output 不再重发过期结果。parentMessages 原有数组形式保留，内部新增按需快照形式；无持久格式迁移。
- 权限：保持既有只读默认、角色收窄、审批和 sandbox 边界。
- 供应链：无新增或升级依赖；许可证/SBOM 以最终完整 verify 的实际结果为准。
- 自审没有以 completed、模型自述或进程退出码代替结果断言；尤其保留了中间 fork 候选的失败。
