# 设置页与事件流跟随改善

本次修改仅限 Desktop 设置界面和共享消息列表。保留现有设置字段、CLI 选择和权限含义。

## 设置体验

- 设置壳层统一导航、内容层级、表单间距、焦点样式和固定操作区；窄窗口改用横向分类导航。
- 主模型的协议、模型名、基础地址和密钥集中展示；自定义认证和额外请求头按需展开；视觉、摘要连接保留独立配置。
- 增加密钥显隐和已保存配置的快捷载入；明确载入表单后还需保存。
- 将原探测入口标为“检查服务可达性”，明确其不验证密钥或模型调用。编辑连接或关闭窗口后，旧探测结果不能覆盖新状态。
- 编辑连接后切换设置分类再保存，仍按连接修改应用。额外请求头的 JSON 格式和值类型在保存前校验。

## 跟随行为

根因之一是 Virtuoso 会在总高度未变化时补偿 scrollTop；只根据位置上移判断用户意图，会自行关闭跟随。另一个问题是原先只允许显式点击恢复，且任务结束会无条件把读者拉到底部。

- 用滚轮、触摸、键盘和滚动条操作标记用户意图，布局补偿本身不改变跟随意图。
- 向上阅读暂停跟随；手动回到底部、End、返回最新按钮或发送新消息恢复。
- 流式数据、测量后的内容高度、视口尺寸变化共用一个受意图约束的跟随入口。瞬时索引定位与实际滚动高度校正配合，避免虚拟列表反复恢复旧偏移。
- 任务完成保留主动上滑的阅读位置，并继续提供返回最新的入口。
