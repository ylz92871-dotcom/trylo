# 文件预览基础设施

Code 和 Work 共用成果入口、文件容器和格式渲染器。预览不接管 CLI、学习系统或任务调度。主界面沿用既有样式。

## 分层与文件归属

| 层 | 位置 | 职责 |
|---|---|---|
| 格式目录 | `src/preview/formats.ts` | 纯格式分类；路由、成果候选和 Work 打开决策共用 |
| 成果证据 | `src/results/output-files/` | 工作区基线/终态、实时文件事件、重叠回合归属和差异；不解析助手文本 |
| 结果模型 | `src/results/*result*`、`work/src/work-artifact-store.ts` | Code 的 outputs 与 Git 变更分开；Work 复用原有领域存储；有界持久化和旧数据兼容 |
| 成果入口 | `src/components/chat/ArtifactPreviewStrip.tsx`、`result-preview-files.ts` | 固定底部入口、文件按钮与全部成果选择，不另建存储 |
| 文件容器 | `src/components/app-shell/FilePeek.tsx` | 前后/多文件切换、全屏、重载、外部打开、所在文件夹、复制路径和错误边界 |
| 阅读组件 | `src/components/preview/` | 各格式视图与交互；容器不承担转换/解码服务 |
| 格式提供器 | `src/preview/providers/`、`src/preview/workers/` | 有界字节到图像/网格、独立 Worker、模型伴随资源；超时/关闭终止自有 Worker |
| 宿主接口 | `src/host-adapter/preview/` | 原生/开发接口适配、Office 合并/队列/缓存、规范化项目范围资源读取 |
| 原生服务 | `src-tauri/src/preview/` | 独立 Office 作业及引擎校验、HTML 资源授权与无应用 IPC 的子 WebView |
| 薄 IPC | `src-tauri/src/commands/preview/` | 参数、权限边界、原始字节响应；复用现有进程退出所有者 |
| 开发适配 | `vite-plugins/preview/` | 对应开发接口、独立网页源、Range 媒体、PDF 离线资源和原样格式解码器 |
| 引擎供给 | `scripts/preview/`、`src-tauri/resources/preview/` | 固定版本、签名/摘要、完整清单、许可和发行资源；二进制资源 Git 忽略 |

`App.tsx` 只接线结果与当前文件状态。关闭、切换工作区/聊天/模式、打开 Diff 或另一文件会令旧读取失效；同路径重载也会刷新渲染器并清除 Office 页缓存。

## 成果收集

每轮捕获规范化工作区基线与终态，配合共享原生文件监听，覆盖非 Git、被 Git 忽略和纯 Shell 产物。扫描过滤运行时/附件/依赖目录，不跟随链接，不把旧文件当本轮新成果。扫描有文件数、深度和访问总数预算，截断会明确记录。

实时事件经过最终文件状态核对，可补上大型工作区的截断扫描。Code/Work 在重叠目录并发时，不能可靠归属的扫描结果不会冒领给某一聊天。结构化、带回合范围的已有事件仍然有效。失败和取消的回合可保留确实产生的文件。清理聊天、后续回合、重复/迟到终态不会借用新回合所有权写回旧结果。

Code 的成果文件与 Git 变更单独保存；Work 继续使用原有 artifact store。结果有显示/持久化上限，保留总数与不完整标记，不伪造全量完整性。

## 阅读能力与明确边界

| 类别 | 当前实现 | 边界 |
|---|---|---|
| PDF | PDF.js 连续阅读、选字、查找、跳页、缩放、适宽/整页、旋转、密码输入 | 离线 CMap/字体/WASM；不执行 PDF 脚本、不编辑表单、没有 OCR |
| Word / Excel / PowerPoint | 独立本地引擎转 PDF，复用同一阅读器 | 字体与复杂文档兼容性可能改变排版；转换输入 50 MB、输出 100 MB、60 秒 |
| Excel 数据 | 全部工作表、200 行 × 20 列窗口及跳转 | 完整单元格显示值；数据视图不还原图表/图片，页面视图负责其呈现 |
| 文本 / Markdown / 代码 | 虚拟行、查找、跳行、全文复制；Markdown GFM；独立只读 Monaco 模型、语言选择、查找和换行 | 复用 90 个内置语言并补 8 个词法高亮；未知语法仍可全文阅读；文本 50 MB、高亮 8 Mi 字符，UTF-8/BOM UTF-16/GB18030 |
| Jupyter 笔记本 | v4/v3 保存的 Markdown、代码、流/错误输出、图像/PDF/HTML、文本和 JSON；单元/多输出导航、搜索与源码 | 20 Mi 字符 / 10,000 单元，不运行内核或脚本；HTML 输出隔离并移除脚本/导航/外部资源，交互 widget 需原环境 |
| 字体 | TTF/OTF/WOFF/WOFF2 私有 FontFace、字号和自定义示例 | 20 MB；只加入当前文档字体集合，关闭移除，不安装到系统 |
| ZIP / JAR / WAR / WHL / NUPKG / VSIX | 有界目录、路径筛选与分页；选中条目读取代码/文本/图片/PDF/CSV/笔记本 | 归档 100 MB / 10,000 项、选中条目 10 MB / 5 秒；不解压到项目；ZIP64/分卷/加密及其他压缩方式仍有限制 |
| RAR4/5 / 7z / TAR / gzip / bzip2 / xz / LZMA / zstd / CPIO / ar | 独立 libarchive 3.8.11 Worker，共用目录与内容阅读组件 | 100 MiB / 10,000 项、实际选中输出 10 MiB、Worker 8 秒、WASM 最大 256 MiB；不跟随链接、不提取项目；加密/分卷及复杂压缩有限制，详见 `archives.md` |
| CSV / TSV | 全文件记录索引、200 行 × 20 列窗口、行定位和横向列翻页 | 保留引号内换行/转义，索引仍在本机内存，不是表格编辑器 |
| 图片 | 适合窗口、原尺寸、缩放、旋转、透明背景；TIFF/HEIC Worker 解码与多幅切换 | Worker 输入 50 MB、64M 像素；系统或提供器不支持的编码会给出失败操作 |
| 音视频 | 系统控件、Range、速度/循环/前后 10 秒；平台失败时使用本地兼容 HLS、按需缓冲与定位 | 兼容层最高 720p/30 fps、默认首音视频轨；24 份格式样本后台通过，实际 WebView2 播放仍未验收；详见 `media.md` |
| HTML | 默认交互、可切换静态/源码；相对与根路径资源、模块、SPA 路由 | 只读网页文件夹授权，20 MB/单资源、512 项/100 MB；未编译 TSX/开发服务器不是可直接执行的 HTML 产物 |
| STL / OBJ / glTF / GLB / 3MF | Three.js 轨道、平移、缩放、取景、视角和线框；OBJ MTL/贴图、glTF/GLB 伴随缓冲/图像 | 项目内资源 10 MB/项、40 MB/64 项；不请求任意外部模型资源；压缩 glTF 扩展仍取决于已配解码器 |
| STEP / IGES / BREP | 独立 OCCT Worker 转网格，交给同一模型视图 | 输入 50 MB、网格预算 300 万三角形；只读网格预览，不是 CAD 编辑/求解 |
| DXF / Gerber | 独立轻量二维渲染器 | 保留失败恢复与原文件外部打开，不宣称全部工程语义 |
| DWG / SolidWorks 等专有 CAD | 清晰提示外部打开 | 尚未提供这些格式的原生解析；不能把当前支持扩大表述为任意文件均可还原 |

通用二进制预览通过有界原始字节接口读取（100 MB），在原生/开发两端检查已打开文件和增长上限；不使用通用无限制读取把整个文件转成 JSON 数组。文本、伴随资源和转换另有更小预算。

## Office 引擎与生命周期

文件到 PDF 是可替换接口。发布配置使用随安装提供的独立转换引擎，不依赖用户先装 Office，也不静默回退到系统安装。自 2026-11-10 起采用 `headless-preview-zh-en-v1` 精简配置，保留转换闭包、全部字体和多语言断词资源；详细范围见 `DEPENDENCIES.md`。开发时可明确设置 `TRYLO_PREVIEW_ENGINE_ROOT`。

每份文件使用独立短路径作业目录与配置，仅复制输入，不回写原件；禁用宏/链接自动更新和不必要的 OpenCL 探测。它不是完整操作系统沙箱。进程采用原有 retained-handle 所有权和退出清理；超时、最后一个视图订阅取消及应用退出均回收自己的转换进程树。原生请求按独立作业标识取消，不能按文件名或进程名取消其他转换；先完成进程及临时目录清理，再释放串行槽位。开发端监听 HTTP 断连并回收自有进程。

前端合并相同请求、串行不同转换，队列最多 4 项；缓存最多 4 份/32 MB，以根目录、路径、大小、修改时间与重载版本区分。每个订阅独立取消，仍有订阅者的共享任务继续；无人使用的排队任务不启动转换器，旧结果不回填新版本缓存。首次核心校验由引擎共享，关闭一个文档不会重复启动摘要任务；发行准备校验全量清单和官方签名。版本升级必须同步版本锁、资源、对应源码/许可和真实转换验收。

同一宿主进程可保留一次成功转换产生的扩展注册缓存，最多 512 项/2 MB，且必须匹配固定引擎 build ID。仅复制 `user/extensions` 到下一份文档的全新临时配置，不复制文档历史、宏/链接策略或整个用户配置；不复用转换进程，不持久化配置种子，不删减随引擎提供的字典。缓存失败仅作为未命中处理，源文件与引擎资源保持只读。`office_profile.rs` / 开发端 `office-profile.ts` 单独负责此优化，首次冷转换仍有初始化开销，不能据此承诺即时预览。

Low 完整性工作区复制出的测试 exe 与引擎启动文件可能继承 Low 标签，不能按正常安装环境解释其临时目录 AccessDenied。只对独立验收副本准备正常 Medium 标签；不改目录 DACL或系统安装。

构建供给入口为 `scripts/build/windows/supply-office-engine.ps1`：复用已验证资源，或获取固定官方 MSI、校验摘要/签名、静默管理解包后生成精简配置，不要求先安装系统 Office。版本锁分别固定完整上游清单和实际分发清单摘要；改动其他 DLL 或资源并改写外部清单也不能绕过构建检查。运行时校验分发清单及固定核心，不逐次读取全部资源。嵌入式 Python 禁止在引擎目录生成字节码，私有运行库 PATH 仅作用于转换子进程。

## 发行与源码配对

`build.beforeBundleCommand` 执行 `scripts/build/shared/preview/verify-release.mjs`，在创建安装包前离线核对精简配置的全部 Office 文件、原样解码器/许可和固定源码归档。先运行 `node scripts/build/shared/preview/fetch-sources.mjs --output <仓库内目录>`，再设置 `TRYLO_PREVIEW_SOURCES_DIR` 指向该目录；缺失或摘要不匹配会阻止打包，不会在应用运行时临时下载补齐。

门禁在根 `_workspace/cache/desktop/preview/release`（可通过 `TRYLO_PREVIEW_RELEASE_DIR` 指定仓库内位置）生成对应源码 TAR、`preview-release.json` 和说明。开发供给与媒体临时缓存统一由 `scripts/build/shared/preview/cache-path.mjs` 定位；已安装产品的运行目录不使用此开发缓存。源码包包括固定上游源码及其原始构建配方、原样许可和 Trylo Worker 适配源码；10 个上游归档的 URL、大小和 SHA256 固定于 `source-archives.lock.json`。公共发布应将对应源码包与清单和同一次安装包一同提供。此门禁验证供给一致性，不替代真实安装和原生交互验收。

## 交互 HTML 隔离

Windows 原生使用独立子 WebView，标签属于禁止应用 IPC 的 `browser-` 命名空间。先建立空白视图，再移除该视图继承的 asset / ipc / tauri 协议过滤器，确认完成后才导航到网页；不能仅依赖 IPC 拒绝或 CORS，否则本地文件协议仍可能打开主机文件。主窗口的既有文件协议保持原有实现。此桥接与锁定的 Wry 0.55.1 过滤器前缀及 WebView2 请求来源匹配，依赖升级测试要求复核契约。其他原生平台尚未接入同等协议隔离，明确回退静态预览。

每次原生预览有独立窗口身份和私密浏览数据目录，避免旧 Service Worker/存储影响下一份文件。授权同时匹配当前窗口身份与 token；旧窗口即使知道新 token 也不能借用授权。资源 canonicalize 后再次证明文件夹边界，已知的其他 grant 不能覆盖当前所有者。关闭文件撤销授权、关闭所属视图并有界重试清理自有缓存目录；文件仍被浏览器锁定时仅保留在应用缓存中。弹窗与跨源顶层导航被拒绝，模态窗口期间隐藏子视图，尺寸更新串行处理。

开发使用独立回环源、不可预测的主机名，以及 opaque-origin、仅 allow-scripts 的沙箱 iframe。静态模式不执行脚本。两端共享 MIME/CSP/资源预算，缺失资源有诊断。网页可按正常网页语义访问网络；这不是网络隔离沙箱。
