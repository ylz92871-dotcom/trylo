## 合同

- 运行入口只来自原生 new CLI 解析，保留同一解析返回的 Node 解释器。设置、预览环境变量和历史配置不能选择旧执行引擎。
- 设置中的运行器切换、CLI 路径覆盖与旧字段退出当前合同；保留连接、权限、学习偏好及聊天历史。旧字段在读取时忽略，下次成功保存时移除，不主动重写用户档案。
- Controller 只调用新 CLI runner；每轮独立进程，CLI journal 持有上下文。保留当前轮的审批、输入、取消、会话关联及原生不可变进程 ID。
- 旧进程常驻、预热、热复用、流翻译、旧资源解析、独立兼容包的暂存和验证脚本退出产品源码与打包。
- 旧源码与仅适用旧运行器的验证保存到开发归档，归档不是依赖，不提供回退或重新启用入口。历史会话和不确定副作用不得自动重放。
- 停止失败必须保留所有权；新轮次启动前检查原生残留。失败终态在后续进程退出时保持可见。
