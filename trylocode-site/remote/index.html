What reaches the phone

离开工位，不离开上下文

手机上看到的是和电脑端同一份状态：任务进行到哪一步、对话说到哪里、哪个操作在等你点头。

实时任务进度

Agent 正在读哪些文件、执行到第几步，以事件流推送到手机；不对劲可以一键停止当前任务。

WS /v1/events

继续当前对话

对话页是电脑会话的镜像，双向同步提问、思考摘要与最终回复，路上想到什么直接发回去。

POST /v1/chat/messages

任务与项目快照

电脑端当前任务、项目与会话状态一览快照，出门在外也能掌握全局进展。

GET /v1/snapshot

敏感操作审批

Agent 要改文件或跑命令时，审批请求推到手机；单次授权只放行这一次，不改变全局策略。

POST /v1/permissions/:id/decision
Security model

固定域名，不固定开口

公网只看到 Cloudflare 边缘，真正的服务只听 127.0.0.1。每一层访问都需要独立凭据，凭据离开不了你的电脑和手机 Keystore。

01

256 位随机配对凭据

配对时生成 256 位随机令牌，电脑端存入本机密钥库（当前为 VS Code SecretStorage），手机端由 Android Keystore 保护。

02

Bearer Token 鉴权

所有 HTTP 请求必须携带 Authorization: Bearer <token>，没有令牌的请求在网关处直接拒绝。

03

单次使用连接票据

WebSocket 先用 Bearer 换取一张 30 秒、单次有效的 ticket，再凭票连接，凭据不会在长连接上反复出现。

04

仅监听回环地址

网关默认只绑定 127.0.0.1:49380，不向局域网或公网直接开放端口，入站流量只能经 Cloudflare 隧道到达。

05

最小数据下发

手机端只收到状态与对话内容，API Key、模型凭据和完整工作区路径永远不会被发送到手机。

Pairing

三步连起来

固定域名不会因重启电脑端 Trylo、切换项目或重新扫码而变化；换了电脑重新配对即可。

STEP 01

启用远程网关

在电脑端 Trylo 的设置中打开远程开关（当前版本在 VS Code 插件设置中），保持隧道模式为 named，网关会在后台就绪。

tryloCode.remote.enabled = true
STEP 02

复制配对数据

运行命令面板里的配对命令，把网关地址和令牌一起复制到剪贴板。

Trylo Code: Copy Remote Pairing Data
STEP 03

在手机上粘贴连接

打开 Trylo Code App，在连接设置中粘贴配对数据。验证通过后，手机就和这台电脑绑定。

App → 连接设置 → 粘贴并连接
