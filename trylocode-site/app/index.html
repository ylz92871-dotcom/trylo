安装说明

下载 APK 传到手机后点击安装；首次安装需在系统设置中允许「未知来源」。配对时在电脑端运行 Trylo（桌面版即将发布，当前由 VS Code 插件承担），使用命令 Trylo Code: Copy Remote Pairing Data 复制配对数据，粘贴进 App 即可。配对令牌由 Android Keystore 保护，App 不会保存工作区文件或 API Key。
