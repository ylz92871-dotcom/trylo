Two rhythms

一次对话，两种节奏

Code 管代码，Work 管成品。思考、执行、交付，在同一个对话窗口里无缝切换。

Code · chat

Chat随时打断

像问同事一样问任何一行代码。回答落在真实的项目上下文里，不猜、不编。

"等等，这里为什么这么写？"
Code · plan

Plan先想想

不急着写代码。先读项目、搜相关代码，展开思考流，方案清晰后给出「一键实施」。

"这个架构怎么改？先想想。"
Code · agent

Agent交给我

读文件、改代码、建测试、跑验证，实时进度、随时叫停。17 个文件，几分钟搞定。

"重构这块，交给我就行。"
Code · cognition

Cognition了解我

一个入口，几段对话：你的回答会落地成证据，成为整套学习系统理解你的起点。

"了解我 —— 你是谁，在做什么。"
Work 模式

Work · 把任务，交付成成品

Work 知道自己要交付什么：一份 PPT、一页网页、一组文档。它按节奏推进，在关键节点停下来等你审批；成果放进产物面板，不满意可以逐页修订。

"帮我做一份季度复盘 PPT，做好发我。"

User Learning

会反过来学习你的搭档

每一次纠正、每一个偏好，都会被认真对待——但学习有门槛，也有刹车。

证据 Evidence → 结论 Conclusion → 用户模型 Model → 策略 Policy
grounding

证据必须真实

只有你实际做过、说过的行为才能成为证据——模型猜的、脑补的，一律不算。

shadow-first

策略先跑影子模式

每条规则都有 enforced / shadow / off 三态，默认在暗处观察验证，确认无扰才真正生效。

brake

拿不准，就不启动

存在高影响且未决的偏好时，Code 与 Work 不会擅自开始执行——宁可停下，也不误解你。

scoping

项目之间互不串台

每个工作区的学习彼此隔离，这个项目的习惯不会被当成那个项目的规则。

Under the hood

安静而可靠的底层

不花哨，但每一项都是你每天会在意的事情。

local-first

本地优先

兼容 OpenAI / Anthropic 双协议的自定义 API 配置，模型由你决定；手机端会话仅存本机。

privacy

密钥不出本机

桌面端密钥本地存储，Android 端锁进 Keystore、禁用云备份——不上传、不追踪、不打扰。

security

安全审批文化

写入前审批、威胁注入扫描、技能安全审查，默认 fail-closed：可疑即拦截。
