# Trylo Android 1.7.0

发布日期：2026-11-16。Android 8.0 及以上，包名 `com.trylo.remote`，版本号 `10700`。沿用原正式签名，支持覆盖升级。

- 全新任务与会话首页：手机聊天、连接电脑一步进入；已连接时展示最近会话与待确认事项。
- 首页、会话、待处理、设备使用固定导航；演示会话成为主动选择的次级入口。
- 手机聊天配置收整为一个主要入口，顶栏保持单行；跨模块切换保留草稿及正在生成的回复。
- 远程会话默认阅读对话正文，执行过程按需展开；查看结果和成员详情时收起输入框。
- Code / Work 共用团队模板选择、成员进度、任务、回复与多轮详情。选择模板不会自动开始任务。
- 修复子智能体续跑重复成员、轮次不及时更新，以及重连后运行状态可能被旧会话重置的问题。离线保留对应会话的成员详情。

## 电脑端兼容性

手机直接聊天无需电脑。基础远程会话继续兼容现有电脑端。

手机发起团队任务需要配套本轮 GitHub 中 Desktop / Service Host 的新协议，并在电脑端开启 Team Access。现有 Windows 2.1.0 安装包发布早于此协议；只更新手机 APK 不会替它增加手机团队能力。手机会按电脑实际提供的能力展示模板；执行、审批与权限继续由电脑端持有。

## 验证范围

120 项相关回归测试、移动端 TypeScript/Vite 构建及 Desktop 类型检查通过。Android 正式包另核验原签名、版本信息和内嵌网页资源一致性。真实手机安装、扫码外网连接及实际模型执行未纳入本轮原生设备验收。
