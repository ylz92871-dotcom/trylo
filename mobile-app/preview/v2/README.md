# 手机远程工作台 · 第二版预览

运行目录：`D:\CC\trylo\mobile-app`。

```powershell
npm.cmd run preview:remote:v2
```

页面：http://127.0.0.1:4186/preview/v2/index.html 。Gateway：127.0.0.1:49424。只绑定回环地址；与第一版 4183/49414 独立。

本版参考 Claude Remote Control 的连续会话、GitHub Agents panel 的任务状态、Google Material 的按需底部操作面板。来源及取舍见 [design-notes.md](./design-notes.md)。

与第一版的主要差异：

- 会话首页、待处理、设备三个入口；当前任务展示状态和项目上下文。
- 会话内提供对话模式、过程模式和共用的结果入口。对话模式把连续的思考和工具记录收为一组摘要；过程模式按接收顺序逐项显示回复、思考摘要、工具调用及结果，详情原位展开。
- 模式切换只改变显示方式，不发送远程操作；保留草稿、工具展开状态及各模式阅读位置。主界面默认过程模式，并记住上次选择。
- 审批采用紧凑提示行 + 主动打开的确认面板；命令、位置、单次授权范围和按钮集中展示。
- 断线保留内容及各会话草稿，重新同步后恢复操作。工具详情支持 Escape 关闭并恢复焦点。
- 桌面预览并排展示两种模式，窄屏显示可切换模式的完整手机界面；返回按钮进入会话首页。

页面、电脑、任务、审批和文件均已明确标记为合成示例。Gateway 是生产实现，客户端复用现有连接层；示例不读取已保存配对，不执行模型或命令。

这是独立交互预览，没有进入正式构建入口，没有生成 APK。正式 UI 与完整 Desktop 逐块事件、多会话后台状态、真实推送和真机验收仍需要后续工作。
