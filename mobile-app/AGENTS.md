# Mobile App 开发约束

遵守根 `../AGENTS.md` 和本工程 `README.md`。应用源码、Android 原生工程、维护中的预览源码、正式测试与构建配置留在这里；截图、验证日志、APK、临时工程和候选版本进入根 `_workspace/`。

改动发布路径时同时检查站点下载准备脚本及对应读取端。不得移动或打印签名凭据；目录整理不授权签名、安装、设备操作或发布。产品用户数据位置遵守现有合同，不重定向到开发外围目录。

本地已构建页面的预览入口沿用 `npm run preview`；开发和原生操作依照工程脚本及 README，不依赖特定外部 Agent 的启动配置。
