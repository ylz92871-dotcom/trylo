# Trylo Code 更新日志

## 1.3.0 — 2026-09-06

任务页新增**产物**区（只读）：

- Work 任务在电脑 `.trylo/out` 生成的文档/表格/演示会列在这里，点行即可查看；图片与文本直接预览，其他格式暂只显示信息（请在电脑端打开）。
- 配套修了一个 P1 的断链：冻结网关此前会丢掉手机发出的 `surface` 字段，Work 通道实际走不通；网关补丁后 `surface` 透传到电脑，Code / Work 分流真正生效。
- 产物接口与对话通道共用同一配对鉴权；单文件 12MB 上限，目录遍历请求直接拒绝。

## 1.2.0 — 2026-09-06

对齐新版 Trylo Desktop（Code / Work 双面）。远程控制不再是老插件时代的单 Agent 视图：

- **远程 Tab 从 5 个减为 4 个**：移除「猫箱」页。电脑端新版本已不再提供猫箱能力（网关 `fun` 固定返回 501），留着只会让人对着失败提示发呆。演示模式里的猫箱数据一并下线。
- **概览 / 任务 / 对话三页新增 Code / Work 切换**：切到 Work 再发送，消息会进入电脑端 Work 通道（文档/表格/演示任务走 Work 提示词与 Work Profile）；切回 Code 则走写代码通道。选择会记住，下次打开还在。
- **模式标签补齐 Cognition**：电脑端 Code 模式现为 agent / plan / chat / cognition，对话气泡与任务页均可正确显示（注：冻结网关会把 cognition 归一为 agent 显示，属已知限制）。
- **电脑离线时显示本机只读缓存**：快照/历史到达即写入（按会话存 60 条，图片只留缩略图）；离线重进先展缓存并标注时间，恢复连接自动被服务端覆盖。电脑仍是唯一权威，缓存不回写。
- 审批页、扫码配对、直连聊天均不受影响；直连聊天的本机存储逻辑不变。

## 1.1.4 — 2026-08-16

本版重点是把聊天部分真正在浏览器里跑起来做验证。之前几个版本只做了源码和 APK 层面的静态检查，从未真实渲染过，所以「点不动」这类问题反复没能确认。这次用无头 Chrome + DevTools 协议加载打包产物，以手机视口和**真实触摸事件**（不是鼠标点击）走通全流程，共 42 项断言全部通过。

- **确认 API 设置可以正常打开**：以真实触摸事件测得设置按钮 44×44px、未被任何元素遮挡，点按后弹层实际尺寸 412×915px、`show-modal` 生效；「API 地址」「模型名称」「API Key」三个输入框均可聚焦、`readOnly=false`、点按落点正确；保存后配置确实写入本地存储且弹层关闭。若你之前装的是 1.1.2，请务必更新——该版本确实存在此问题。
- **失败的回复不再凭空消失**：过去请求出错时，整条回复会被直接删除，只弹 2.2 秒的提示，看起来就像应用把问题吞了。现在失败的气泡会留在对话里，显示服务商返回的真实原因（例如「请求过于频繁或额度不足（HTTP 429）」并附带上游详情），旁边提供**「重试」**按钮，可连同原始图片附件一起重发，不必重新输入。失败记录也会写入历史，重启后依然可见。
- **复制按钮增加兼容回退**：表格与代码块此前只用异步剪贴板 API，在部分 Android System WebView 里会被拒绝且静默失败（按钮毫无反应）。现在会自动回退到 `execCommand('copy')`，并且只有确认写入成功才显示「已复制」。已验证复制出的内容为标准 Markdown 管道表格。
- **放大过小的点按区域**：附件按钮原为 36×36px、设置页顶部「取消/保存」仅 32px，均低于 44px 的手机最小点按标准，容易点不中。现视觉尺寸调整为 40px 并通过透明扩展区补足到 44px，顶部按钮也提高到 44px。
- **其余功能均已实机验证**：服务商列表 24 项、文字对比度实测 16.28:1（远高于 WCAG AA 的 4.5:1）、每行 52px；模型预设点一下即填入输入框；图片可发送、气泡内显示、点击全屏查看，且**发送的是全尺寸图而非缩略图**，本地只保存缩略图（本次实测历史仅占 1.7KB），完整图片数据不落盘。

## 1.1.3 — 2026-08-15

- **选模型界面不再灰暗看不清**：Ionic 默认的深色 action sheet 把选项文字压得很暗，23 个服务商挤在一起几乎分辨不出来。现在弹层底色提亮、文字改为高对比白色、每行加高到 54px 更好点，当前选中的服务商用金色高亮，并加上「选择模型服务商」标题；列表按「国内 / 海外 / 自定义」分区排序，每项前面标注归属地区。收起状态下的下拉框文字也一并提亮。
- **可以自己配模型了**：每个服务商下方新增「常用模型」一键填入列表，标注用途（代码专用 / 深度思考 / 图片理解 / 免费额度等），点一下就填进模型名输入框；同时输入框仍可手输任意模型 ID，遇到官方新模型不必等更新。
- **火山方舟 Coding Plan 已内置**：豆包/火山方舟补齐 `doubao-seed-code-preview`（Coding Plan 代码专用）、Seed 1.6 旗舰/flash/thinking 以及 vision-pro 视觉模型，并附控制台直达链接。注意：Ark 的模型 ID 带日期后缀且随订阅不同，若控制台显示的 ID 与内置的不一致，直接在输入框改成你自己的即可。
- **表格新增复制键**：表格上方加了工具条，点「复制」会把渲染后的表格还原成 Markdown 源码（含分隔行，单元格内的 `|` 会转义）写入剪贴板，可直接粘贴到任何 Markdown 编辑器。
- **支持上传图片和文件**：输入框左侧新增图片、附件两个按钮，可多选（单条消息最多 6 个）。
  - 图片会自动缩放到最长边 1024px 再发送，避免手机原图动辄几 MB 白烧 token；消息气泡里显示缩略图，点击可全屏查看。
  - 文本类文件（`.txt/.md/.json/.csv/.log` 及各类源码）会以代码块形式内联进提示词，因此**不支持视觉的模型也能读**。
  - PDF、Office、压缩包等二进制格式会明确提示不支持，而不是发一堆无意义的字节过去。
  - 图片按各家格式正确封装：OpenAI 兼容用 `image_url` data URL，Anthropic 用 `source.base64` + `media_type`。
  - 未安装任何新原生插件：Capacitor 的 `BridgeWebChromeClient.onShowFileChooser` 本身就实现了 `<input type="file">`，可直接唤起系统相册/文件选择器与相机。
- **注意（存储权衡）**：本机历史只保存**缩略图**，完整图片数据发送后即丢弃，不写入 localStorage（浏览器约 5MB 上限，存几张原图就会撑爆导致历史损坏）。所以翻看旧对话时图片是低清预览，且重新发送不会复用原图。
- 只带图片、没有文字的消息现在也能正常发送与保存。
- 安全：从历史读回附件时只接受 `data:image/` 形式的内联图片，远程 URL 会被丢弃，避免存档渲染时触发外部网络请求。

## 1.1.2 — 2026-08-15

- **API 地址现在可以自己改了**：之前即使把输入框解锁，保存也会被丢掉——`normalizeConfig()` 对所有非「自定义」服务商都会强制用内置地址覆盖你填的值。现在地址和模型名一律以你的输入为准，留空才回落到该服务商的默认地址，因此可以填自建代理、中转站或其他区域的域名。
- 地址输入框旁新增「恢复默认」按钮（只在你改动过时出现），改错了可以一键还原。
- **服务商从 8 个扩充到 23 个**：新增智谱 GLM、腾讯混元、百度文心千帆、阶跃星辰、MiniMax、零一万物、百川、讯飞星火、魔搭 ModelScope、Google Gemini、xAI Grok、Groq、OpenRouter、Together AI，并补充「自定义 (Anthropic 兼容)」。
- 安全限制保持不变：地址仍必须是 HTTPS，且不允许带账号密码、查询参数或 #片段；请求格式与鉴权头仍由所选服务商决定（这两项填错只会导致调用失败，所以不开放手改）。
- 地址与模型输入框关闭自动大写/纠错/拼写检查，地址栏改用 URL 键盘。
- 顺手修掉一个隐患：设置页原本用 `DIRECT_PROVIDERS[length - 1]` 取兜底服务商，依赖数组末位；服务商列表扩充后这个位置变了。改为按 id 查找 `custom`。

## 1.1.1 — 2026-08-15

- **彻底修复「API 设置点不动」**：上一版把设置弹窗挂到了一个 `position: absolute` 且没有尺寸的容器里。由于 Ionic 的 `ion-modal` 是 `position: absolute; inset: 0; contain: strict`，它会按这个 **0×0** 的父容器计算大小并被裁掉——按钮其实点得到，但弹窗被压成了看不见也摸不着的一个点。现在容器改为铺满视口的 `position: fixed; inset: 0`，弹窗自身也显式锁定为全屏尺寸。
- 弹窗容器改为挂到 `ion-app`（与 Ionic 自身 `getAppRoot()` 一致），并且只让 `ion-modal` 接收触摸；空白层不再拦截点击，`ion-toast` 也保持原本的穿透行为，不会挡住下面的聊天。
- 输入法弹出时不再遮住输入框：Activity 补上 `windowSoftInputMode="adjustResize"`。
- 表格与代码块渲染优化随本版一起生效（1.1.0 的构建产物早于这部分改动，实际并未包含）。

## 1.1.0 — 2026-08-14

- 修复直连聊天里 **API 设置无法点击**的问题：设置面板与会话抽屉不再是可拖动的半屏卡片，改为标准全屏弹窗，并移出会话滚动容器（overlay 独立挂载到 body），避免下拉手势吞掉点击、以及滚动容器错位导致按钮点不到。
- 聊天顶栏新增**齿轮「API 设置」入口**，未配置 Key 时按钮高亮提醒；不再需要先打开会话抽屉才能找到设置。
- 所有聊天与设置里的可点击元素统一放大到 ≥44px 触控区，补上按下反馈，去掉移动端点击高亮延迟。
- API Key 的显示/隐藏改为独立文字按钮（原先嵌在输入框内部，在安卓 WebView 里几乎点不到）；输入框关闭自动大写、自动纠错与拼写检查。
- 设置面板底部新增大号「保存设置」按钮，不再只依赖顶部小号文字按钮。
- 修复**流式回复不逐字输出**：CapacitorHttp 会把 `window.fetch` 换成一次性返回的原生请求。现在优先使用 WebView 原生 fetch 获取真正的 SSE 流，仅在跨域被拒时回退到原生桥接，并对整段回复做渐进式呈现。
- 修复「停止生成」无效：请求超时与中断信号现在都能真正取消，已生成的内容会保留；离开聊天页会自动中断在途请求。
- 错误提示更明确：区分 API Key 无效/无权限、地址或模型不存在、限流额度不足、服务商故障、网络不可达与请求超时（上限 2 分钟）。
- 生成中不再隐藏输入框，发送键就地变为红色停止键；输入法回车键提示为「发送」。
- 长回复中向上翻阅时不再被新 token 强行拉回底部，只有停在底部时才自动跟随。
- **优化 AI 回复的表格与代码渲染**：含表格或代码块的回复气泡自动拉宽到整屏（原先被压在 80% 宽度里），表格单元格允许换行不再被超长中文撑爆，仍需横滑时显示边缘渐隐与滑动提示，数字列保留右对齐并使用等宽数字。
- 代码块头部改为语言徽标 + 行数显示，新增「换行 / 不换行」切换（长代码不必反复横滑），复制按钮在剪贴板被拒时不再抛错；触控区放大到 30px 以上。
- 任务清单（`- [x]`）渲染为真实复选框并对齐图标，行内代码可正常断行不再溢出气泡。
- 打包脚本改为从 `package.json` 读取版本号命名 APK，避免版本号写死。

## 1.0.0 — 2026-08-13

- App 更名为 **Trylo Code**，重构为两大功能区：顶部「聊天 / 远程」分段切换。
- 新增**直连聊天**：手机直接请求模型服务商（豆包、DeepSeek、通义千问、Kimi、SiliconFlow、OpenAI、Anthropic 及自定义 OpenAI 兼容接口），流式输出，体验接近豆包。
- 直连聊天的会话记录保存在本机（localStorage），支持新建、重命名、删除；API Key 保存在 Android Keystore，模型地址/名称等非敏感配置保存在本地。
- 远程控制部分完整保留：概览、任务、对话、猫箱、审批五个标签及扫码配对。
- 启用 CapacitorHttp，安卓原生层代理出站请求，绕开 WebView CORS 限制。
- 首个公开版本：统一应用名与版本号，并启用正式构建的代码/资源压缩。
- 每个模型服务商使用独立的 Keystore 密钥槽；内置服务商地址不可改写，自定义地址强制 HTTPS，避免 API Key 被误发或外泄。
- 隔离远程配对令牌与模型密钥的安全存储操作，严格校验配对站点，并为 Gateway 请求增加超时保护。
- 禁止 Android 明文网络与应用数据备份，移除未使用的外部文件共享入口；限制本地会话及单次回复大小。
- Markdown 内容继续经过 HTML 清洗，外部链接仅允许 HTTPS。
