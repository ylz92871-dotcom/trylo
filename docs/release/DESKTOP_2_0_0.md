# Trylo Desktop 2.0.0：任务带来经验，经验回到任务

2026-11-09 · 一次面向长期协作的大版本更新

Trylo 2.0 来了。

这次，我们把工作台、独立的新 CLI、原生工具和预览体验一起向前推进，并将 **中央学习系统 Beta** 带到本次发布的中心。我们希望 Trylo 可以持续理解任务、理解你的工作方式，也认真对待做过的事情留下的经验。让每一次协作，都有机会成为下一次协作的起点。

## 最大的更新：中央学习系统 Beta

学习需要有人统筹。哪些材料值得读，什么问题值得继续，经验要交给哪个子系统，又应该在什么条件下重新判断——中央学习系统开始围绕这些问题组织独立的学习过程。

本次更新完善了学习机会、目的与条件、材料来源、资源安排、工作分派及反馈回读之间的连接。中央可以继续思考、读取材料、咨询、交给领域子系统，或等待新的事实、实际采用反馈与可用资源。任务产物可以返回原来的学习目的，后续的使用和纠正也能继续参与修订。

工具、方法、协作与技能等学习模块得到完善；用户学习继续保持自己的采集与应用设置。中央控制与调度机制也有更新，加入或改进了有依据的机会判断、资源协调与反馈处理。具体实现与说明随本次核心源码更新公开。

**把任务里的经验，变成可以再次使用、也可以被纠正的做法。** 这是 Trylo 2.0 最重要的方向，也将是接下来内测的重点。

### 由你选择是否参加

- 在 **设置 → 学习 → 中央学习系统 · 测试功能** 开启或关闭，默认关闭。
- 开启并保存后，首次启用随下一次正常任务启动；已有学习配置按当前工作区恢复。
- 关闭并保存会停止当前工作区的中央学习后台，保留已有经验。用户学习等独立选项仍按各自设置管理。
- 累计 token、模型调用授权及单次思考配置清楚可见；学习可能在普通任务结束后继续或等待。
- 学习产物与工具执行权限分开管理，仍遵守审阅与授权边界。

中央学习仍是 **Beta / 测试功能**。部分受控路径已有实际采用与反馈记录，但跨领域泛化、长时间运行与长期收益还需要更多真实使用来验证。检查学习仍暂未开放；其他子系统以当前实际开放能力为准。我们欢迎具体的问题、失败案例与反例，让系统在真实反馈中继续完善。

## 工作台全面进化

这次 UI 的目标，是让复杂工作能够更清晰、更平稳地展开。

Code 与 Work 的共同界面、消息、工具过程、结果与预览进一步统一；任务入口、项目导航与对话定位更加成熟。布局更克制，信息层次更清晰，减少视觉噪声，让注意力更多留在正在完成的事情上。

新的 README 使用本次真实任务截图：文档交付、交互网页、原生浏览器与 3D 场景。它们展示实际工作过程；具体任务表现仍取决于模型、权限、设备和材料。

## 预览模式，更接近完整工作现场

完善文档、网页、图片、媒体、归档与工程类文件的预览链路，改进资源加载、文件切换和预览反馈。任务结果可以在侧边继续查看与检查，网页成果可以直接交互，代码差异与文件内容也能回到具体产物。

浏览器与电脑预览继续围绕原生工作体验完善。工作过程中看到的状态和结果，应当尽可能与实际执行保持一致。

## 独立的新一代 Trylo CLI，正式成为唯一引擎

本版 Desktop 彻底接入独立研发的新版 Trylo CLI。旧 CLI 退役，设置中的旧引擎切换及相关运行、解析与打包入口退出产品。

新 CLI 修复了多项已知问题，并在此前多轮压力与长任务测试基础上，继续优化上下文估算、使用量统计、压缩与接续处理。后台任务、工具调用、权限反馈与会话生命周期相关修复也纳入这次核心源码更新。

## 内置工具，原生使用体验继续完善

浏览器、桌面、文件与命令等内置能力同步更新。优化工具接线、权限与失败反馈、结果呈现及打包依赖，让工具更自然地参与任务。工具需要的权限仍由用户选择；拒绝、失败与执行结果按实际情况返回。

## Windows 2.0.0，与首版 macOS / Linux Beta

Windows 版本号直接进入 **2.0.0**。

macOS Apple Silicon 与 Linux x86_64 本次同步开放 **第一版 Beta** 二进制，来自各自私有仓库的 GitHub Actions 构建。平台适配源码保持私有，核心源码按公开边界同步。

**请特别注意：macOS 和 Linux 均为首版测试版，预计存在较多问题。** Linux 以 Ubuntu 24.04 / X11 为当前构建基线；Wayland、其他发行版及更多设备组合仍需内测。macOS 首版为 Apple Silicon，签名与系统权限体验仍待完善。欢迎愿意一起完善平台体验的用户参加。

## 邀请码内测，即将开始

邀请码分为标准内测与优质内测两类。测试阶段提供每日 token 配额，旗舰模型池及相关限量 API 权益面向优质内测用户开放。
