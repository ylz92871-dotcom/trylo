# Desktop 1.0.2 / Android 1.6.0

本次发布只同步清单审核的产品代码、测试、构建配置与下载元数据。日志、模型请求、录屏、研究库、浏览器资料、私有配置及签名身份不进入源码或制品。旧 CLI 源码不发布。

## 修复

- 对暂存 Windows 可执行副本设置明确 Medium 标签，避免 Low 构建目录降低 Node 与工具子进程完整性；便携版提供固定随包路径的启动修复。
- 输入健康探针检查令牌、实际启动器及基础解释器标签，输入状态不受版本缓存掩盖。
- 工作区内绝对文件路径经过同一真实路径检查后可读写；外部、设备、链接越界与 shell cwd 原有边界保留。
- 新版→旧版→新版时创建新会话，通过可见历史重新建立上下文；替换进程使用原协议取消通道，连续新版轮次仍续接。
- 同步工具运行身份、MCP 图像交付、中文 shell 编码、手机连接恢复、中继及近期桌面更新。

## 构建与验证

- 新 CLI 完整 11 步 verify 全绿，4,206 个测试名称、38 项合同检查；暂存的 2,784 个文件及 962 个生产 JS 已绑定。
- Desktop 初始专项 264 项、权限与子进程专项 47 项、切换与会话专项 75 项通过。重复覆盖不相加作为唯一测试数量。
- 工具、浏览器、输入探针回归，真实 Low→Medium 写入反例及暂存手机网关/二维码链路通过。
- Android 重新构建通过 lint、原签名身份校验及 25 项回归；中继 7 项回归通过。
- CoWork 剥离；桌宠自包含单文件压缩；安装器 LZMA，ZIP deflate 9；发布默认无前端源码映射，诊断可设 `TRYLO_BUILD_SOURCEMAPS=1`。
- 密钥扫描覆盖提交代码、资源、前端与 APK，并比较本机配置密钥字节。固定 Node 二进制按已记录 SHA 核对，其中厂商测试字符串单独复核。

## 边界

公开核心包默认新版 CLI，旧版保持外接兼容；本机旧 CLI 另行重编译并通过隔离模拟服务验证。CoWork 的旧实验依赖单独保存，普通 Work 不需要。

本记录不替代干净 Windows 安装、完整原生 UI、真实模型、全工具输入或 Android 真机验收。当前运行的开发 Desktop 和用户工具进程未重启、未终止。
