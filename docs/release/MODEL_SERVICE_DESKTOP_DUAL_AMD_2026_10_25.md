# Desktop 文本模型同步与 AMD 双账号分流

2026-10-25。延续已经上线的账号、模型授权与配额服务；本轮把 Desktop 模型选择和实际 CLI 调用接入同一服务，并将第二个 AMD 账号加入原免费池。

## 当前行为

- Desktop 原模型菜单保留“我的配置”，免费池从当前登录账号同步。只展示获授权的文本模型，按模型 ID 去重。目前两把真实 API 都返回 15 项目录，Desktop 展示其中 10 个文本模型；OCR、语音和判别模型 5 项保留在控制台，其专用执行接口仍未开放。
- 打开菜单、窗口重新聚焦、账号变化和打开时的定期刷新会同步目录。加载、无授权、登录失效、同步失败以及已选模型失效都有提示；没有写死的 Grok 选项或付费回退。原有自配 API 与保存的配置继续独立使用。
- 一个上游池、一个用户授权、同一原子账本，下面配置 primary / secondary 两个加密凭据。每人每天 **1000 次，总计跨两个 API、所有池内模型共用**。按北京时间重置；原共享池 100000/日、池并发 2、用户并发 1、全局并发 4 不变，均为 Trylo 限额。
- 执行器优先选择空闲且较久未使用的账号。明确的 401/403、429、连接错误会触发不同冷却期；单次已发出的调用不会切换密钥重放。已明确结束的失败按已发出的一次请求结算并释放并发；超时、断流等不确定调用仍保留一次扣额及原有保守并发保护。
- 密钥仍在首尔服务器 AES-256-GCM 加密。第二账号绑定 source、endpoint、protocol 和 slot。重复密钥不能增加为另一个账号；修改地址会使旧凭据失效。管理员通过原密钥表单选择账号 1/2 保存，不回显旧密钥。
- Service Host 持有原生账号会话，给 CLI 分配内存中的模型限定本机凭据，通过 127.0.0.1 随机端口桥接 JSON/SSE。账号 bearer 和供应商密钥不交给渲染器；本机凭据只进子进程临时环境，不写全局模型设置。退出账号会撤销本机连接并中断进行中的流。相同账号/模型复用本机凭据，避免长任务在 128 轮后耗尽连接名额。
- 选择免费池时，不携带自配 API 的地址、密钥或额外头；账号模型无授权就停止。显式选择个人配置的会话会清除全局免费池覆盖，避免对话间串线。

## 从真实失败修到真实调用

初次实际 CLI 调用失败，原始 `run_result: failed / http_409` 与不确定账本均保留。复现发现 AMD 返回 `System message must be at the beginning.`：CLI 的基础提示、项目规则、上下文分成多条 system 消息，而目录查询和单句 API 探针不会触发此问题。

AMD 适配器现在把 system/developer 文本指令按顺序合并到开头一条，保留用户、助手和工具历史顺序。对应测试包含中途更新的指令和完整工具历史。明确的 SSE error 会结束本次请求；没有完成标记的截断流继续保留不确定用量，未通过删账或放宽配额掩盖失败。

本轮真实验证：

- 两个 AMD 账号各自发现 15 个模型，目录一致。
- 首尔离线维护探针通过同一个既有授权和账本，普通/流式调用各一次，记录证明两个账号各处理一次且均 HTTP 200；既有授权 ID、已用额度均保留。
- 使用现有 YLZ 原生登录的隔离副本，经打包资源中的 Node → Service Host NDJSON RPC → 本机网关 → 正式账号服务 → AMD → 打包 CLI 完成回答 `TRYLO_PLATFORM_OK`。
- 第二次真实 CLI 任务通过 `read_file` 读取隔离测试文件，再进行第二轮模型请求并回答 `TRYLO_TOOL_OK_2417`。终态 completed、2 轮，包含 tool_use / tool_result；原用户会话文件摘要前后一致。复制的会话已从私有探针目录删除。
- 后端 60 项、Desktop 模型/会话/账号相关 84 项、Service Host 模型与既有账号/重连 10 项测试通过，共 154 项。TypeScript + Vite 生产构建通过；UI 静态检测返回空问题列表。
- 公网独立核对 4 条资源的实际字节摘要、5 条受保护接口匿名 401、运行服务包与本机构建相符、单池单授权、1000 次上限、两条加密凭据及 0600 主密钥；最近 3 条真实请求均结算一次。

这些结果没有证明其余 9 个文本模型均逐一调用成功，也没有证明所有工具、原生窗口或安装包已验收。浏览器操作被 Work 设置禁用，本轮未绕过设置进行实屏检查。已发布的官网 Desktop 1.0.6 安装包未重打；当前源码、前端 dist 与 Service Host 资源已更新，开发版需完整重启以加载新的服务方法。
