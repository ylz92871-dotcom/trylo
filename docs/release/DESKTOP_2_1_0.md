# Trylo Desktop 2.1.0：软件去后台工作，桌面留给你

2026-11-11 · 一次稳定与能力更新

这次最重要的变化：内置工具有了自己的软件工作台。Trylo 操作 SOLIDWORKS、AutoCAD 这类软件时，应用运行在独立的隐藏桌面上——不占用你的屏幕，不移动你的鼠标，不抢焦点。你可以继续做自己的事；想看的时候，在对话旁打开软件坞，看到的就是真实的应用画面。

## 不占用电脑的软件操作与预览

- Code 与 Work 共用同一个软件坞：真实应用窗口出现在对话旁边，支持应用/窗口切换、刷新、展开与明确停止。
- 应用运行在独立的 Win32 桌面，与你正在使用的桌面隔离；Trylo 不会终止你桌面上已有的任何应用。
- SOLIDWORKS 有独立的模型视图，走原生图像导出，只读，不打断正在进行的建模命令。
- 手动接管会先等在途的 API 调用完成，再让你的输入生效；对话框对你和模型保持可见，认证与安全决策不会被自动接受。
- 执行与审批权威仍在原有 CLI 与权限边界：只读模式拒绝写入，自动模式放行已授权工具，明确关闭的电脑能力不会挂载该表面。

## 新增生图与视频工具

- 新增生图与视频内置工具，使用你在设置里配置的连接，生成真实文件并保存到工作区。
- 生成调用需要审批；视频任务先返回作业号，稍后查询结果，不会重复提交。
- 生成结果可以直接在对话里预览。

## 压缩更稳，提问更自然

- 修复 Desktop 长任务压缩空转的问题，改进自动压缩估算与近期历史保留，长任务接续更稳。
- 完善提问机制：支持自由回答与选项式提问，提问与输入区接线在一起，媒体创作也会主动向你提问。
