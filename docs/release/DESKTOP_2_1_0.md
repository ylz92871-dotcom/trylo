# Trylo Desktop 2.1.0

2026-11-16 · Windows 更新

这次更新重点修复了打断工具后无法继续对话的问题，并调整了 CLI 中会阻断正常任务的过度限制。软件工作台、生图与视频工具等此前尚未发布到 Windows 安装包的改动，也一起进入本次版本。

## 打断之后，继续同一个对话

- 停止指令会传到正在执行的工具。停止尚未结束时显示“正在停止”；需要立即结束进程时，可以再次点击停止。
- 上一次操作结果不确定时，会保留现场信息，供后续检查和处理；同一个对话仍可继续接收任务和使用工具，不再要求先手动处理内部恢复状态。
- 单个工具失败、可选媒体配置缺失或工具列表变化，不再无故锁住整个会话。不会自动重做结果不确定的历史写入。
- 移除了进程会话数、工作流输入和输出摘要的部分隐式限制，保留用户明确设置的限额和权限选择。
- Code 与 Work 共用这套停止、恢复和状态反馈。

## 软件在独立工作区运行

- 内置软件操作可使用独立的 Windows 桌面；你可以在对话旁的软件坞查看真实应用画面，切换窗口、刷新、展开或停止。
- SOLIDWORKS 模型预览使用原生图像导出。手动接管先等待正在进行的 API 调用结束，再交还输入。
- 认证、安全确认和写入权限继续遵循当前授权。

## 媒体工具与长任务体验

- 新增可配置的生图、视频工具，结果保存到工作区并可在对话中预览。视频生成按作业查询进度，避免重复提交。
- 改进长任务的上下文压缩、近期历史保留及提问输入，支持选项和自由回答。

## 下载与安装

- 本次只重新构建 Windows x64 安装包。安装前请退出 Trylo；安装包尚未签名，Windows 可能显示安全提示。
- macOS Apple Silicon 与 Linux x86_64 继续提供 2.0.0 首版 Beta，本次没有重新构建。
- 中央学习系统仍为可选测试功能，默认关闭。
- 安装包旁提供 SHA-256 校验清单和配套预览组件源码。
